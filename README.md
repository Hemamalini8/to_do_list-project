# 🧾 Student Form – Simple JavaScript Project

### 🚀 Overview
A **simple Student Form Web App** built using **HTML, CSS, and JavaScript**.  
It lets users **add, view, and delete student details** 

---

### 🌐 Live Demo  
👉 **[Click Here to View the Project]( https://hemamalini8.github.io/to_do_list-project/
)**  
---

### ✨ Features
- 🧍 Add student details (Name, Age, Email, Password, Gender, Course)  
- 🔒 Passwords shown as masked (`*****`)  
- 🧹 Clears input fields after adding  
- ❌ Delete any entry instantly  

---

### 🛠️ Tech Stack
- **HTML5** – Page structure  
- **CSS3** – Styling  
- **JavaScript** – Form logic & table updates
